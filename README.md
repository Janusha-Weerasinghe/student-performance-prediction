# ⚙️ Environment Setup

## Create Project Folder

```text
D:\AI-Projects\student-performance-prediction
```

---

## Initialize Git

```powershell
git init
```

---

## Create Conda Environment

```powershell
conda create -n student-performance python=3.12 -y
```

---

## Activate Environment

```powershell
conda activate student-performance
```

---

## Verify Python Version

```powershell
python --version
```

Expected output:

```text
Python 3.12.x
```

---

## Upgrade pip

```powershell
python -m pip install --upgrade pip
```

---

## Install Required Packages

```powershell
pip install pandas numpy matplotlib seaborn scikit-learn xgboost joblib jupyter notebook
```

---

## Verify Installed Packages

```powershell
pip list
```

---

## Generate Requirements File

```powershell
pip freeze > requirements.txt
```

---

## Create Project Folders (PowerShell)

```powershell
mkdir data,notebooks,src,models,reports,tests,docs

mkdir data/raw,data/processed,data/external

mkdir reports/figures,reports/metrics
```

---

## Create Initial Files

```powershell
New-Item README.md -ItemType File

New-Item requirements.txt -ItemType File

New-Item .gitignore -ItemType File

New-Item LICENSE -ItemType File
```
